GT2 Arcade Modes

How Gran Turismo 2's Arcade Mode turns menu choices into races, and what a win unlocks. The arcade code also sits unused on the Simulation disc, identical to the copy on the Arcade disc, so these rules hold for the port's Arcade Mode too. Checked against runs of the Arcade disc itself.

From the title to the race and back

GT2 does not keep all its code in memory at once. Parts of it, called overlays, are loaded from GT2.OVL when needed: "ovl2" below is the arcade menu code, "ovl3" builds garage cars, "ovl5" plays movies. The port's Arcade Mode row does what the Arcade disc's Start Game does: set the hand-over bytes and load the arcade menus. Every page writes one field of a 724-byte request; the race build turns it into the shared race set-up, and after the race the game returns the player to the menus.

"+1", "+2" are byte offsets in the small hand-over block the title leaves for the next part of the game.

What a win unlocks

Arcade progress is one byte per course: the difficulties won (Easy, Normal, Difficult) and a count of Normal wins. Only a first place in a Road Race writes it, on the result page after the replay. Easy wins open nothing.

Courses

Three per list are open. The other eighteen need a GT Mode license in the same save: B, A, IC, IB, IA, S open three each, once all ten tests of the license have a result. The Arcade disc alone never opens them; its progress page says so.

Reverse layouts

The license, and the course won at Difficult. Five Normal wins count as a Difficult win.

Class S and race cars

Each of the 10 class S cars and 11 of the 24 race cars is tied to one course: win it at Normal or Difficult. The Class S row appears with the first S car.

Ending credits

Arcade: every road course won at Normal or better. Simulation: the GT World Cup won in GT Mode. Both are movies only the Arcade disc has.

Player cars use fixed arcade set-ups: block 32 of usa_arcade_data.dat for Racing, block 33 for Drift. Garage cars (your own or a guest's) keep their own tune; ovl3 rebuilds them on the GT Mode car database.

Difficulty is the rubber band

The "rubber band" holds the AI back when it is ahead and helps it when it is behind. Easy, Normal and Difficult change only rule bytes 23 to 28 of the event: how hard and from how far that happens. AI grip stays 100 in every arcade event; the class picks the opponents.
