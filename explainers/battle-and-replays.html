GT2 port · two-player battle, replays and ghosts

GT2 Battle and Replays

Two features built on the same idea: a race is its set-up plus the players' inputs. The 2-player battle is GT2's race kind 0: two player cars, split screen, standing start. Replays and ghosts in the port use their own file format: the set-up, a start seed, the physics choice and each human player's inputs per race frame. Everything else is simulated again on playback, and the file carries fingerprints that confirm the playback is the race that was driven.

The battle

In UGT2R: Arcade Mode, 2-Player Battle, Road or Rally, then GT2's 2P course list (the lighter 2p_* course files, each locked by its forward course's license), both players' cars on one page with each player's own pad, laps and each player's color, setting and transmission, then the race. The keyboard and first gamepad are player 1, the second gamepad is player 2, and Y exchanges the two gamepads. The result goes to the save as battle wins per player.

Where the laps are kept

GT2 keeps each player's lap table inside the save block in memory: player 1's at save +0xC5A8, player 2's at save +0x10AC0 (byte offsets from the start of the save block). Each car's input record is built from its own pad: player 2's from the second pad.

Battle options

The battle uses GT2's two-player options: battle laps, a handicap that places one player further back on the grid (handicap 2 put player 1 about 19 m of course distance behind player 2), boost and wear, a two-player rubber band, both cars' gap banners, and the finish of either player. A tied battle goes to player 2.

What a replay is

GT2 replays work the same way: its playback simulates the race again. Both physics choices in the port (classic and modern) give exactly the same result every time from the same inputs, so storing the inputs is enough. New replays and ghosts come from the port itself; GT2's own replay format is not written.

The input stream

A stream is a list of runs. Each run is 7 numbers:

[count, flags, buttons, steer, throttle_step, brake_step, held]

count race frames share the same record: the same 5-byte record GT2's own replays store (after the button layout is applied; see input) plus the race pad's held buttons. A digital pad changes rarely: a 6,806-frame race is 519 runs.

Left out: paused frames (they run the pause menu, not the race) and Start / Select, which are the viewer's own buttons during playback.

The session seed

Each save holds one session seed (see career saves). Every race's start seed is drawn from it and written into the race's replay. The seed feeds the event build's classic random draws and the modern physics. The modern physics itself draws nothing.

A battle records both players' streams; player 2's stream drives car 1. More than two players are refused with the reason.

Ghosts

GT2's time trial keeps a ring of the last 4 laps with a start snapshot each, copies the best to a ghost car, and restores the lap's snapshot every lap. The port does the same from your own run, without the ring: the whole run is kept and the lap's start state is simulated again from it.

After an Arcade time trial or rally, the run becomes the course's ghost (<saves>/ghosts/<course>.gt2replay) when its best lap beats the stored one. On the result page, L1 turns the next run's ghost on or off, and Options has GT2's ghost display setting (not in replays, always dark, dark within 3 or 5 m).

Limits

  • Replays play back only on the same disc data and the same mods they were recorded with; anything else is refused with the reason.
  • Replays and battles support at most two human players.
  • Replay sound follows GT2's replay rules (no jingle) but has no mix of its own.
  • Different from GT2 on purpose: no 4-lap ring (the whole run is kept), and a better ghost is kept automatically.
