Inside GT2's Events

What GT Mode's races are made of: one data file of event records, a fixed set of entry checks, a random draw of five opponents, and a prize table per event. Checked against the race set-ups the game actually builds. At the end: why the completion figure stops at 98.20 %, and why a cheat-device code makes it 111.21 %.

Everything is data

Every GT Mode event is a 156-byte record in one file on the disc, /carparam/usa_gtmode_race.dat inside GT2.VOL. The same file holds the opponents' cars and the lists of cars an event accepts. The license tests sit in a second file with the same record layout. The code supplies only a few tables: the sorted list of event IDs, the unlock lists, the points per place, and the courses for "random course" events.

The license "prize records" (LIx00) are not races: each holds only the car you win for all-gold in that license. 102 events have no fixed course and draw one of 39 courses at random each time.

Reading an event ID

IDs are seven characters. The digits carry meaning the code uses: the first pair says how many races the championship has (00 = a single race), the second pair which race this is.

GT30503 is race 3 of the 5-race GT305 championship; GJL0002 is GT League Japan race 2, a single race. Other IDs: FREERACE01..03, FREECHAMP0501..05, the machine tests G400, G1000, GMAX. "GT League", "Special Events" or "Endurance" exist only as menu pages: an event belongs to whichever pages name it.

One record, 156 bytes

The 64 rule bytes are copied as one block into the race set-up, where the AI and the physics read their parts (see Inside GT2's AI). The power limit is in PS; prize money is stored in hundreds of credits.

Who may enter

When you pick an event, the game runs these checks in order. The first one that fails shows its message and the race does not start. Nothing else blocks an event: not money, not days, not a previous race.

  1. You have a current car.
  2. Pro leagues (PFL, EPL): all 16 national GT League races won.
  3. GT World Cup: all 6 pro league races won.
  4. Rally: the car owns dirt tires.
  5. License: you hold the license the event names (B, A, IC, IB, IA or S).
  6. Drivetrain: FF, FR, MR, RR or 4WD, if the event sets one.
  7. Car kind: a two-way rule used by two events each way. What exactly it tests is not known.
  8. Modification: no racing modification, racing modification required, or no tuning parts at all (tires and weight reduction are not checked).
  9. Power limit: the car's stored power in PS, which tuning parts update, must not exceed the limit.
  10. Eligible-car list: the car must be on it, if the event has one. Maker and country rules exist only this way.

The power check reads the shown PS. 61 of 618 engines carry a hidden multiplier between 96 % and 118 % (the R34 GT-R 116 %), so some cars make more real power than the limit sees. The physics page covers that. Before the race the game also changes your garage car: dirt tires go on for a rally and come off for anything else.

Drawing five opponents

Each record lists up to 16 opponent cars, each a complete car with its parts and settings. At every race start the game draws five of them at random. It draws again when a car repeats or is not sold in your save's region, up to 64 tries. With fewer than five entries, cars repeat.

Each pick copies the opponent record into a full car set-up: 27 part choices, gearing, LSD, downforce, alignment, springs, dampers, stabilizers, ASC and TCS, and a power multiplier. A rally lists one car: the opponent is a recorded run stored with the event, played back as a ghost.

Why some opponents look wrong

Two classic complaints come straight from this draw. Six endurance events start their lists with one stray car (the RUF BTR2 at Apricot Hill, the Vector M12 LM at Trial Mountain), so it shows up in some races and not others. And the draw never checks power, so a few lists hold cars over the event's limit. Both are covered on GT2's Classic Bugs.

The draw follows load timing

The random seed depends on when loading finishes. The same button presses gave different opponents with console-speed and fast disc loading, so a faster load changes the field (see random numbers).

Prizes and points

What a race pays

  • Each record carries its own prize money for places 1 to 6. First prizes run from 3,000 to 500,000 credits.
  • A win in a single event also gives one prize car, chosen at random from up to four. 82 events have prize cars. The car is always stock, and its color is drawn when the race starts.
  • Championship races pay race 01's prize table each round, with no car. Taking the title pays the bonus plus one prize car.
  • No prize car is added when the garage already holds 100 cars.
  • Credits are capped at 99,999,999.

Championship points

Every car scores, the AI too, and the same six cars race every round. Ties go to the player: the standings sort keeps equal totals in car order, and you are car 0.

Licenses

Six licenses of ten tests each, taken in a fixed order. Within a license the tests can be run in any order. A license counts as held when all ten tests have a result; the save stores no separate "license" flag.

B→A→IC→IB→IA→S

Grading

  • Each test has four target times: gold, silver, bronze and "kids".
  • A kids time does not pass on its own. Each kids run adds one to a near-miss counter; when it reaches the test's limit (5, 10, 20 or 30 runs) the test passes with the lowest result.
  • All ten gold, the first time: the license's prize car goes to the garage. Licenses pay no money.
  • Leaving the course ends a run with no grade. That is decided by the race code, not the test data.

Why completion stops at 98.20 %

The status screen's completion figure comes from one calculation: the number of events whose best result is a win, times 100, divided by 248 − 25 = 223. It counts over all 248 records but divides by 223.

The 25 that don't count

A result is saved only for single races and for a championship's final place, which goes under race 01's slot. So these 25 records can never get a result from play, and the divisor leaves out exactly them:

  • 6 license prize records (LIx00)
  • 3 machine tests (G400, G1000, GMAX)
  • 16 championship races 2 to 5 (four championships × four)

The cheat-device code writes "won" to every one of the 248 slots (and 12 bytes past them), so the 25 slots play can't reach count too. Any save editor that marks every event won does the same. On an unmodified US v1.0 card no way past 100 % was found. Only the NTSC-U v1.0 disc was checked; PAL's 100.91 % is a PAL matter.

What the save keeps

  • A days counter, +1 for every event or license race started from the menus.
  • The best place per event, half a byte each. Trophies on the event pages come from it.
  • Races, wins, total prize money; license results and times; the garage and credits.

There is no "unlocked" bit anywhere. Every unlock is re-checked from the saved results every time. The championship and prize state are rebuilt before every race, and there is no autosave.

Room for new events

For modders: the first limit is not the file format but the RAM buffer GT Mode inflates the race file into: 181,440 bytes for a 170,566-byte file. That leaves about 10,800 bytes, roughly 65 more events if they reuse existing opponent cars.
