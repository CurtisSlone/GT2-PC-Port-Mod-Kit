GT2's Classic Bugs

The bugs GT2 players know, each traced to its cause in the game's code or data. Everything here was checked on one disc: the US Simulation disc, v1.0 (SCUS-94488). Polyphony fixed some of these in later versions; only v1.0 was checked, so later behavior is never claimed here.

Before you read

  • This page describes the original game. The port's classic mode reproduces the disc, bugs included. Where a fix is sketched below, it is a description of what a fix would take, not a promise.
  • Odd physics is not on this list. Strange but harmless physics behavior is GT2's character and is noted only at the end.
  • Numbers like +0x3A88 are byte offsets inside the save data in memory.

Save and progress bugs

B1

Machine Test records eat the garage

reproduced

The most serious bug on the list, because it destroys saves. Players report hundreds of "No Name" cars, a garage over 100, corrupted credits and licenses after Machine Test runs.

Cause
The step that inserts a record adds one to the table's count with no cap at 8. A 9th qualifying run leaves the count at 9 in an 8-slot table. From then on both of its loops run past the table and write into whatever comes next, and every insert raises the count again. The max speed table sits right before the garage, which is why players see it as a max speed bug.
What happens
Run on a GT Mode save in memory: a 9th max speed record leaves count 9; when that car improves its record, garage car 0's ID becomes FFFFFFFF, the unknown "No Name" car. A slow 1000 m run is placed in slot 9 and sets the max speed count to 153.
Fix sketch
Only raise the count while it is under 8, loop to at most 8, and clamp the three counts on load. That repairs the tables of a save that already overflowed, not a garage that was already overwritten. It changes nothing for saves that never overflowed.
B2

Completion stops at 98.20 %

reproduced

The completion figure divides event wins by 223. Four of those 223 can't be won on the US disc: the two Vauxhall Tigra events (the car is hidden in the US region and its dealer isn't linked) and the two Peugeot 206 events (no menu item leads to them). 219 / 223 = 98.20 %.

Full walk-through with the math on Inside GT2's Events.

B2b

Completion over 100 %

reproduced

The same count covers all 248 event slots but still divides by 223. Play can never write the other 25 (license prize records, machine tests, championship races 2 to 5), but a cheat can. The v1.0 cheat-device code "All Races Completed" marks all 248 as won: 248 / 223 = 111.21 %.

No path past 100 % was found on an unmodified US v1.0 card. A fix would count only the 223 slots play can write, capped at 100.00.

Opponent and event bugs

Causes traced, no fix chosen: a later disc version (v1.1 or v1.2) would show which opponents Polyphony intended.

B3

The stray endurance opponent

cause found

Each listed endurance race sometimes fields one car that doesn't belong. The cause is in the data: each event's opponent list is a run of consecutive records with one stray record at the front, exactly the car players name. The five opponents are drawn at random, so the stray car appears in some races only.

B4

AI over the power limit

cause found

The power limit is checked only against your car. The opponent draw re-rolls repeats and region-hidden cars, never power. Building each opponent the game's way and reading the peak of its engine curve:

EventLimitOpponentPeak
ETM0001300Vector M12 LM~690
MRC0003600Vector W8~643
HTC0002300Ford GT40~311
HTC0003400Corvette Sting Ray '67~441

Peak power in PS, a lower bound: turbo boost is not counted, so turbo cars read low, and the Grand Touring Car Trophy list (Supra, GT-R, 3000GT) was not finished.

B5

Themed cups accept any car

cause found

The entry check has no country, maker or body-type rule; those exist only through eligible-car lists. The national GT Leagues, the Wagon Cup, the Muscle Car Cup, the Light-weight K Cup and the Historic Car Cup have no list, so any car under the power limit with the right license gets in.

This may be a design choice. A fix could add lists built from each theme (the data has room for 162 more) or keep GT2's open rules.

B6

Tahiti Maze race 2: the opponent crashes at the start

reproduced

Players report the opponent turns left too early, hits the barrier and stays there. The rally opponent is not the AI: it is a recorded run of pad inputs played back and simulated by the physics every time. The recording for this event drifts off the line it was made on, hits the wall shortly after the start, and the replayed inputs never bring it back.

Share of the 1,656 ticks (1/30 s steps) after launch. Fix sketch: a new input recording, or hand a ghost stuck against a wall to the AI driver, which already takes the ghost over after its finish.

Menu and label bugs

B7

Car Wash price

cause found

The page art says "ONE WASH Cr5,000", the yen figure. The game checks for and charges 50 credits. The charge is right; the label is wrong. Fix sketch: re-letter the picture.

B8

Rome Short Course Preview starts the race

cause found

Each event page has a Preview item (no player car) and a GO! item. On the Italian GT League page, the Preview item for GIL0001 lacks the "no player car" flag bit, so it starts a real race. It is the only such item in all 3,382 menu pages. Fix: one bit in one menu word.

B9

Muscle Car Cup license badges

cause found

The Special Events page draws the badges as art. The Muscle Car Cup row shows A, IC, IB, copied from the Luxury Sedan Cup's row. The event records require IA for all three races, and the entry check uses the records.

K1

A misspelled random course

cause found

The list of courses for random-course events spells new_parmaS as new_paramaS. No course has that name, so a 1-in-39 pick would load course 0 under that name. Not seen in play yet. Fix: one string.
