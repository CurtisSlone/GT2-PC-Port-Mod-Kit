GT2 State Machine

A game is a set of states (the title, a menu page, a race in progress, the pause menu) and the button presses or timers that move it from one to the next. This page maps GT2's: which part of the game runs, which screen or page is up, which sub-state, where the cursor is, and how each state reads the controller. The port uses this map to make sure its redrawn menus take the same paths as GT2, not just show the same pictures.

253states mapped (front end, GT Mode, race)
1,951transitions (button to next state)

Why it matters

On the garage car page (0x3A1), Cross on Settings goes to page 0x308, then 0x309, then the parts pages 0xF9 / 0xFA. A redrawn menu that took a player from the same car page to a dealer's maker page instead would look right and still be wrong. The map catches that kind of mistake: it compares where each press leads, not what is drawn.

Four levels, one id

Every state is mode/screen[/sub] plus a cursor. The mode is which part of GT2's program is loaded: the game loads its code in parts (overlays) from GT2.OVL as needed, one for the title menus, one for GT Mode, one for races, one for Arcade, one for movies. Each change of a level is one record, with the button that caused it.

One record

 "id":"gt/page/0x3A1","cursor":"item 4 code 9 ->0x3A1",
 "cause":"Cross@2708 chain","at":"row 23/32","profile":"gt.page"}
F
the field (one 1/60 s screen refresh) when the change happened
cause
the latest button press within 300 fields (900 for a mode change); chain when the same press already caused an earlier change; repeat X for a held button repeating; auto for timers and loads
at
the cursor when the button went down: what the confirm acted on
profile
how the new state reads the controller (table below)

How many pages there are

GT Mode is built from 3,183 reachable pages. Most of them are per-car pages: one parts page set and one info page per car. The map visited every item up to two steps from the city map, then the first few items on each page (events and licenses first), and one example of each per-car kind.

Message pages were only ever cancelled, never confirmed (Yes would buy or sell). Races were left through the pause menu's Exit. Watching the states never changes the game: races play exactly the same with the map on or off.
