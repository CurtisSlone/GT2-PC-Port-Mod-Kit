GT2 Random Numbers

Every random thing Gran Turismo 2 does, from the opponents on the grid to the music at the start, comes from one tiny number generator. Sixteen places in the game ask it for a number, and the clock at that moment decides what comes out. Nothing random happens while you are actually racing.

1generator, no shared state
16places that draw a number
65,536different values it can give
0random draws inside a race

The generator

A "seed" is the number a random generator starts from. In GT2, each place that wants a random number keeps its own 32-bit seed. A draw multiplies the seed by 17, adds 17, stores it back, and returns the seed folded onto itself: the high half XOR the low half (XOR is a bit-by-bit "one or the other, not both"), written into both halves. So there are only 65,536 different draws.

Where the seeds come from

There is no single shared random state. Almost every draw starts a fresh stream from the VBlank count (the number of 60 Hz screen refreshes since power-on) at the moment it runs. That is why loading speed changes the opponents: a faster load reaches the draw on a different frame.

Numbers like 0x801F0070 below are addresses in the PlayStation's RAM, where the game keeps that value. "+0x54" is a byte offset inside a record (the race set-up, the race state).

VBlank total

VBlank counter at 0x801F0070

Opponents, random course, prize car colors, free-race field, the result page object, the prize car. Read without waiting.

Board seed

race set-up +0x54

Re-drawn at each course load after waiting one VBlank, but kept in replays, so a replay rebuilds the same trackside boards.

Music seed

race state +0x70 = VBlank + boot seed

One stream per race session; each race start (race, Test Run, replay) takes the next draw. The boot seed mixes the hardware timers once at power-on and nothing else reads it.

The draw sites

What each random draw decides, and when it happens. Some of these are rare (a random-course event, a prize car) and a few only exist on the Arcade disc.

Opponents

GT Mode, when the event is built

Six picks per event (the first slot is then given to the player's car). Draw an entry of the event's list until the car is sold in this region; a car already on the grid is redrawn with chance 29/32, at most 64 times; then a color, drawn again once if it is dull.

k = d % n          until usable
repeat: d & 31 < 29 -> again
color  = d % colors

Trackside boards

course load

For each of five board sets: shuffle its images, then walk the board positions while images remain, placing one when a 12-bit draw is at most the position's chance.

slot = d % n       until free
place if (d & 0xFFF) <= chance

Race music

race start

One draw from the session stream picks one of six tunes, played at GO.

tune = d % 6

Result page object

result pages

Four draws: an angle, two unused, and a value 80 to 207 (stored at +0xAC of the object).

angle = d1 & 0xFFF
+0xAC = (d4 & 0x7F) + 80

Prize car

win payout

Which of the event's prize cars you win, after a single-race win or a championship. Its color was drawn before the event.

car = d % prize count

Random course

event build

For an event whose course is the random name (103 events, such as the one-make races and FREERACE events): one of the list's courses.

course = list[d % len]

Prize car colors

event and license build

One color draw for each of up to four prize cars.

color = d % colors

Free-race field

free races

After the opponent menu: six cars from the chosen list, each redrawn until usable, then a color.

Arcade side

Arcade disc and attract demos

Five more copies of the opponent and color picking, for the Arcade side and the attract demo set-up (never used on the Simulation disc), and two words for link (two-console) races.

Nothing random inside a race

No random draw happens during a race frame. Physics, AI, collisions, the camera and the sound are fully decided by the race set-up and the controller inputs. That is how replays work: a replay stores no random state at all. It rebuilds the boards from the stored board seed and runs the race again from your recorded inputs.
