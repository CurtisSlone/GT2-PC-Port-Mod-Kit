MODS FOLDER

Each subfolder here is one mod. Its files take the place of the game's files of the same name when the game
starts; data\ is never changed. Paths are the same as in data\gt2vol\inflated (or raw), for example:
  mods\GreenMR2\carobj\t2mgn.cdp
  mods\MyTrack\crsobj\zz_mytrack.tro.gz

load-order.txt lists the mods to load, in order (later ones win). A line starting with # is off.
Without load-order.txt every folder loads, alphabetically.

Full guide: guides\02-MODS.md. Use a separate memory card for modded play.
