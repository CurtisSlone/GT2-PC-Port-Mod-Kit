MODS FOLDER

Each subfolder here is one mod. Its files take the place of the game's files of the same name when UGT2R
starts; data is never changed. Paths are the same as in data/gt2vol/inflated (or raw), for example:
  mods/RedMR2/carobj/t2mgn.cdp
  mods/MyTrack/crsobj/zz_mytrack.tro.gz
A mod's textures-override folder holds full-resolution pictures for the remaster look (gt2-tools writes it).

load-order.txt lists the mods to load, in order (later ones win). A line starting with # is off.
Without load-order.txt every folder loads, alphabetically. With it, only the folders it names load.

Full guide: guides/03-MODS.md. Use a separate memory card for mods that add cars or courses.
