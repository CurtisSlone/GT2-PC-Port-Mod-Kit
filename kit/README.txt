GT2 PC PORT - MOD KIT

gt2_track_tools-0.4.0.zip   the GT2 Tools add-on for Blender 4.2 or newer (Windows and Linux). Install it from
                            Blender: Edit > Preferences > Get Extensions > the small arrow top right >
                            Install from Disk... > pick this zip (do not unzip it). It replaces GT2 Track Tools 0.3.
                            Full steps: ..\guides\04-TOOLS-SETUP.md

samples\   track descriptions made for this kit (no game data):
           sample_track.json + .glb + .csv   a 2.9 km road course drawn as a Blender-style line
           oval_scenery.json                 an oval with grandstands, trees, lamps and sponsor boards
           climb.json                        a point-to-point hill climb

The mod kit's program is one folder up: ..\gt2-tools.exe (Windows) or ../gt2-tools (Linux).
Start with ..\guides\04-TOOLS-SETUP.md, then the guides 05 to 12.
