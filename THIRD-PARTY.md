# Third-party tools and software

This page lists every program from outside this project that the kit uses, where it comes from, what it is used
for, and which guide step needs it. **None of the tools in section 1 are included in this release.**
`kit\setup-kit.bat` downloads them from their authors' own release pages, checks each download against the
SHA-256 below, and unpacks it into `kit\tools\`. You can also download them yourself from the links.

Open-source libraries compiled into our own executables are listed with their licenses in
`THIRD-PARTY-LICENSES.txt`.

## 1. Downloaded by setup-kit.bat

### pez2k's GT2 tools

Written by **pez2k** (https://github.com/pez2k/gt2tools). They are the community's standard tools for GT2 car
files, and the kit's car guide relies on them. They are free downloads from the author's GitHub releases. The
repository has no license file, so this project does **not** redistribute them. setup-kit.bat fetches the exact
versions below from the author's release page. All credit for these tools goes to pez2k and the contributors named
in each tool's readme.txt (adeyblue, Leo2236, Xenn, Submaniac and others). The gt2tools README asks people who use
the code or research in other projects to let pez2k know.

| Tool | Version | Used for | Guide step | Download (author's release) | SHA-256 of the archive |
|---|---|---|---|---|---|
| GT2ModelTool | 2.1.0 | car model `.cdo`/`.cno` ↔ editable `.obj` + `.json` | 05-CARS, "Model" | https://github.com/pez2k/gt2tools/releases/download/GT2ModelTool210/GT2ModelTool_v210.7z | `f7eaee7173264bc7b0bc1515c0327e010213bf23149fe1c0152d12254ec592ec` |
| GT2TextureEditor | 0.4 | car paint `.cdp`/`.cnp` ↔ editable bitmaps + palettes | 05-CARS, "Paint and colours" | https://github.com/pez2k/gt2tools/releases/download/GT2TextureEditor04/GT2TextureEditor_v04.7z | `9db55360082255787e3bb283b3e6d8f828edc540504f979a386c31f22eacba0c` |
| GT2DataSplitter | 0.8.0 | car specs and events `usa_gtmode_data.dat` ↔ CSV | 05-CARS, "Specs" | https://github.com/pez2k/gt2tools/releases/download/GT2DataSplitter08/GT2DataSplitter_v08.7z | `fa8156a848479528cf720b0e10a8940f5418acc9907fc3ab6934f333580c489c` |
| GT2CarInfoEditorCSV | 0.1 | car names and colour names `.carinfoa`/`.carcolor` ↔ CSV | 05-CARS, "Names" | https://github.com/pez2k/gt2tools/releases/download/GT2CarInfoEditorCSV01/GT2CarInfoEditorCSV_v01.7z | `044a8fd4baabab873c0b974dbb7774d681c2816564950a3379ac83deb97044fb` |

What each one needs to run:

* GT2ModelTool 2.1.0 needs the **.NET 8 Runtime** (Microsoft, free:
  https://dotnet.microsoft.com/download/dotnet/8.0, "Run console apps"). setup-kit.bat checks for it and tells you
  if it is missing. It never installs anything by itself.
* GT2DataSplitter 0.8.0 was built for .NET 6, which Microsoft no longer supports. setup-kit.bat writes
  `kit\tools\GT2DataSplitter.bat`, which runs it on .NET 8 by setting `DOTNET_ROLL_FORWARD=Major` (the tool is
  unchanged). If you have the .NET 6 Runtime installed, the tool also runs directly.
* GT2TextureEditor 0.4 and GT2CarInfoEditorCSV 0.1 need .NET Framework 4.7, which is part of Windows 10 and 11.
  GT2CarInfoEditorCSV includes `CsvHelper.dll` (Josh Close, MS-PL / Apache-2.0) in its archive.

## 2. Install yourself

| Software | Who | Used for | Guide | Where |
|---|---|---|---|---|
| **Blender 4.2 LTS or newer** (required for the track tools; tested with 4.2.3 LTS and 5.2) | Blender Foundation, GPL | drawing tracks; the starter scene; viewing exported courses | 03-EXPORT, 04-BUILD-A-TRACK | https://www.blender.org/download/ (or the Microsoft Store / Steam) |
| .NET 8 Runtime (only for the car tools) | Microsoft | runs GT2ModelTool and GT2DataSplitter | 05-CARS | https://dotnet.microsoft.com/download/dotnet/8.0 |
| An image editor with indexed-colour (palette) support, e.g. GIMP or Paint.NET (optional) | various | editing car paint bitmaps and course textures | 05-CARS | any |

setup-kit.bat looks for Blender in the usual places: Program Files, Steam, the Microsoft Store, and
`blender.exe` on the PATH. It checks that the version is 4.2 or newer and installs our add-on into that Blender.
It never downloads or installs Blender. If you keep Blender somewhere else, run `kit\setup-kit.bat
"D:\path\to\blender.exe"`.

## 3. Shipped in this release, made by this project

* `psx-play.exe`, `gt2-course.exe`, `gt2-trackc.exe` and `modules\`: binaries built by this project.
* `kit\gt2_track_tools-*.zip`: the GT2 Track Tools Blender add-on. It is Python, as all Blender add-ons are,
  and is public domain (CC0 1.0), which is compatible with Blender's GPL. The guides, scripts and samples are
  CC0 too: see LICENSE.txt.
* `kit\samples\`: track descriptions and a sample centre line drawn for this project. They contain no game data.
* `cards\blank.mcd`: an empty, formatted memory card image, generated by the runtime.
